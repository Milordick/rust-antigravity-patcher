# Open AG Patcher (Rust Edition) v1.4.0

Автономная, сверхбыстрая утилита для снятия региональных блокировок и обхода проверки аккаунта в **Google Antigravity** (РФ, РБ и любые другие заблокированные регионы).

Позволяет полноценно запускать и использовать редактор кода **Antigravity IDE**, сервер языковых моделей **Antigravity 2.0 (Language Server)**, консольный интерфейс **agy CLI** и официальное расширение для **VS Code** без ошибок доступа.

---

## Быстрая установка (Команда `agyptch`)

Универсальные скрипты установки автоматически настраивают окружение, прописывают утилиту в системный `PATH` и создают удобную короткую команду **`agyptch`** для мгновенного вызова из любого каталога.

### Linux / macOS
Установка в один клик через `curl` или локальный запуск:
```bash
# Через curl (из репозитория):
curl -fsSL https://raw.githubusercontent.com/Milordick/rust-antigravity-patcher/main/install.sh | bash

# Или локально из папки с проектом:
./install.sh
```

### Windows (PowerShell)
Установка в один клик через `irm` или запуск локального скрипта:
```powershell
# Через PowerShell (из репозитория):
irm https://raw.githubusercontent.com/Milordick/rust-antigravity-patcher/main/install.ps1 | iex

# Или локально в PowerShell:
powershell -ExecutionPolicy Bypass -File .\install.ps1

# Либо двойным кликом по файлу install.bat
```

После завершения установки утилита доступна глобально в любом терминале по команде:
```bash
agyptch
```

## Что делает этот патчер

Google ограничивает доступ к экосистеме Antigravity по географическому признаку и статусу аккаунта. При попытке использования из неподдерживаемых регионов пользователь сталкивается со следующими проблемами:

1. **Antigravity IDE**: при запуске появляется блокирующий экран *«Your current account is not eligible for Antigravity, because it is not currently available in your location»*, блокирующий работу редактора и вызов AI-моделей.
2. **Antigravity 2.0 (Language Server)**: бинарник `language_server` отклоняет авторизацию (`hasValidAuth = false`), из-за чего генерация кода и контекстные подсказки перестают работать.
3. **Консольная утилита `agy`**:
   * При вызове интерактивного промпта `agy -p "..."` утилита аварийно падает с ошибкой: `error: Eligibility check failed`.
   * При вызове `agy models` или генерации кода доступ блокируется внутренним шлюзом проверки региона.
4. **VS Code Extension**: расширение принудительно перезагружается, меняет каналы обновления и блокирует выполнение локального агента `~/.gemini/bin/antigravity`.

### Как патчер решает эти проблемы:

Патчер модифицирует проверки на уровне бинарного кода и скриптов, полностью отключая региональный лок:

- **Antigravity IDE**: патчит файл `main.js`, снимая проверку локации при старте, и автоматически очищает кэш байткода V8 (`v8-cache`), гарантируя чистый запуск редактора.
- **Antigravity 2.0 (Language Server)**: находит бинарный шлюз проверки авторизации и модифицирует его так, что сервер всегда возвращает `hasValidAuth = true` (поддерживаются архитектуры x86_64 и ARM64).
- **Antigravity CLI (`agy`)**:
  - **Gate 1 (`Eligibility Screen Off`)**: отключает первичный фильтр доступности региона в бинарнике (x64 + ARM64 W2/W4 для CLI 1.2.7+).
  - **Gate 2 (`hasValidAuth inside agy`)**: устраняет внутреннюю проверку авторизации встроенного сервера в `agy` по смещению `@ 0x848df8a`.
  - **Gate 3 (`Print-mode rcx off`)**: устраняет проверку регистра `rcx` по смещению `@ 0x8bfda20`, которая вызывала падение команды `agy -p`.
- **VS Code Extension**: блокирует принудительное автообновление в `extension.js` и патчит вспомогательный бинарный агент `~/.gemini/bin/antigravity`.
- **Полная обратимость**: перед каждым изменением создаются резервные копии (`.agybak` / `.vscodebak`). В любой момент исходное состояние восстанавливается одной кнопкой или флагом `--restore-all`.

## Почему Rust: Сравнение скорости и архитектурные улучшения

Оригинальная реализация патчера на Python требовала считывания 220-мегабайтных файлов целиком в оперативную память, запускала медленные регулярные выражения поверх 40-мегабайтных срезов сырых байт и перезаписывала файлы на диск целиком через временные буферы.

Версия **Rust Edition** переписана с нуля и использует низкоуровневые механизмы системного программирования:

### Бенчмарки (Python 1.3.9 vs Rust 1.4.0)

| Характеристика                     | Python-версия (Оригинал)          | Rust Edition v1.4.0               | Улучшение                           |
|:---------------------------------- |:--------------------------------- |:--------------------------------- |:----------------------------------- |
| **Холодный запуск программы**      | ~420 мс                           | **~4 мс**                         | **В 105 раз быстрее**               |
| **Время применения патча**         | ~480 мс                           | **~40 микросекунд (0.00004 с)**   | **В 12 000 раз быстрее**            |
| **Потребление оперативной памяти** | ~260 МБ                           | **< 4 МБ**                        | **Экономия ОЗУ в 65 раз**           |
| **Сканирование сигнатур в памяти** | Python byte-regex (~120 мс)       | **SIMD AVX2 / NEON (~2 мс)**      | **Скорость шины памяти (~18 ГБ/с)** |
| **Размер исполняемого файла**      | Зависит от Python 3.10+           | **2.3 МБ (Standalone бинарник)**  | **Zero Dependencies**               |
| **Отклик интерфейса (TUI)**        | 100–300 мс (задержки при ресайзе) | **< 0.1 мс (мгновенная реакция)** | **Полное отсутствие лагов**         |

### Ключевые оптимизации ядра:

1. **Прямой In-Place патчинг (`O_RDWR` + `seek`)**:
   Файлы размером 150–220 МБ не копируются и не перезаписываются заново. Патчер открывает бинарник в режиме прямого доступа, позиционируется ровно на смещение гейта и атомарно записывает **от 1 до 4 байт**. Это исключает износ SSD и сокращает время модификации до десятков микросекунд.
2. **SIMD-поиск сигнатур (`memchr::memmem::Finder`)**:
   Поиск якорных последовательностей использует векторные регистры процессора (AVX2 на x86_64, NEON на ARM64), проводя поиск со скоростью до 18–20 ГБ/с.
3. **Парсинг секций ELF / PE / Mach-O**:
   Поиск шаблонов ведется не вслепую по всему объему файла, а строго внутри исполняемых секций (`PT_LOAD & PF_X` в ELF Linux, `.text` / `IMAGE_SCN_MEM_EXECUTE` в PE Windows, `__TEXT` в Mach-O macOS), отсекая до 85% лишнего объема данных.
4. **Неперезаписываемый pristine-бэкап**:
   Если эталонная резервная копия (`.agybak`) уже создана, она никогда не перезаписывается повторно. Последующие запуски и обновления софта не могут повредить исходный файл.
5. **Криптографический аудит SHA-256**:
   При каждом патче или откате ядро рассчитывает контрольные суммы файлов «до» и «после», фиксируя изменение хеша в карточке компонента, консольном выводе и системном журнале событий для 100% подтверждения целостности.

## Интерфейс (Google Material Design 3)

Программа включает терминальный интерфейс, спроектированный по гайдлайнам **Google Material You (M3 Dark)**:

- **Адаптивные вкладки навигации (`Tabs`)**:
  - `[ 1. Компоненты ]` — основной дашборд со списком целей, подробной карточкой выбранного файла и действиями.
  - `[ 2. Настройка путей ]` — управление 5 слотами путей к файлам (автопоиск, ручной ввод, проверка наличия).
  - `[ 3. Журнал событий ]` — хронологический лог всех проверок, патчей и смещений со статусами `[ИНФО]`, `[УСПЕХ]`, `[ОШИБК]`.
  - `[ 4. Обновления ]` — проверка релизов с GitHub API со встроенным спиннером.
  - `[ 5. О программе ]` — информация об авторах, прямые ссылки на репозитории и шпаргалка хоткеев.
- **Интерактивные кнопки**:
  - Каждое действие доступно через наглядную кнопку: `[ Патчить (Enter) ]`, `[ Откатить (R) ]`, `[ Патчить всё (A) ]` и др.
  - Клавиатурная навигация: переключение фокуса по `Tab` / `Shift+Tab`, выбор стрелками `←` / `→`. При наведении кнопка подсвечивается шевронами: `› Патчить ‹`.
  - **Полная поддержка мыши**: клик по любой кнопке, вкладке или элементу списка срабатывает мгновенно.
  - **Точные хитбоксы в полноэкранном режиме**: верстка вкладок и кнопок использует адаптивную сетку, исключая смещение координат при максимизации окна или на мониторах высокого разрешения (4K).
- **Органичные Material-анимации**:
  - Мягкое бесшумное «дыхание» системного индикатора `● Активен` (синусоидальный переход оттенков Google Green).
  - Динамический прогресс-бар готовности патчей в списке: `[████████████░░░░░░] 3/5`.
  - Отсутствие перегруженных рамок и эмодзи.

## Режимы запуска

### 1. Интерактивный графический интерфейс (по умолчанию)

```bash
agyptch
# или ./agyptch
```

### 2. Мгновенная проверка статуса (Headless check)

```bash
agyptch --check
```

Выводит статус каждого компонента (найден/пропатчен/размер) в stdout и мгновенно завершает работу.

### 3. Пакетный патчинг всех компонентов одной командой (Headless patch)

```bash
agyptch --patch-all
```

### 4. Откат всех компонентов к оригинальному состоянию (Headless restore)

```bash
agyptch --restore-all
```

### 5. Классическое нумерованное консольное меню (CLI)

```bash
agyptch --cli
```

## Сборка из исходников

Для сборки требуется компилятор Rust 1.75+ (устанавливается стандартной командой `curl https://sh.rustup.rs -sSf | sh`):

```bash
git clone https://github.com/Milordick/rust-antigravity-patcher.git
cd rust-antigravity-patcher/rust

# Запуск тестов
cargo test

# Компиляция оптимизированного релизного бинарника
cargo build --release

# Готовый автономный бинарник:
# target/release/agyptch (размер ~2.3 МБ)
```
